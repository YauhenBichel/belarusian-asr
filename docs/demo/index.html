Open source · Apache-2.0 · CPU only

Belarusian speech recognition that runs on a CPU

NVIDIA's Belarusian FastConformer, packaged for ONNX Runtime, with a server that speaks OpenAI's and whisper.cpp's APIs. Measured on FLEURS against Whisper large-v3.

How accurate

Benchmark

CER and WER are corpus rates after lower-casing and removing punctuation. "No digits": FLEURS writes numbers as digits and this model says them in words, which is right but scored as wrong.

Use it

pip install "belarusian-asr[server]"
belarusian-asr transcribe clip.wav
belarusian-asr serve --port 11805      # POST /v1/audio/transcriptions, POST /inference

Model: NVIDIA stt_be_fastconformer_hybrid_large_pc, CC BY 4.0, trained on Mozilla Common Voice; ONNX export by OpenVoiceOS. Audio and references: FLEURS (Conneau et al., 2022), CC BY 4.0. Comparison: whisper.cpp with ggml large-v3.
